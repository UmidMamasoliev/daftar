# decisions/ — qabul qilingan qarorlar

Har qaror — bitta fayl: `decisions/NNNN-<nom>.md` (NNNN — tartib raqami: 0001, 0002...). Format:

```markdown
# NNNN — <qaror, bir jumlada>
Sana: YYYY-MM-DD
Nima hal qilindi: <qaror>
Nega: <sabab — eng muhim qism>
Nimani oʻzgartiradi: <ta'siri>
```

Qarorlar hech qachon oʻchmaydi — sabablari bilan tarix boʻlib qoladi. Keyingi agent (yoki olti
oydan keyingi siz) «nega bunday qilganmiz?» deb soʻrasa — javob shu yerda.
