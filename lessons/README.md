# lessons/ — xatolardan chiqarilgan qoidalar

Foydalanuvchi agentni tuzatdimi — shu yerga qoida yoziladi: `lessons/qoidalar.md` ichiga bitta
qator qoʻshiladi. Format:

```markdown
- [YYYY-MM-DD] <qoida: nima qilinadi yoki qilinmaydi> (sabab: <qisqa>)
```

Agentlar ishni boshlashdan OLDIN shu faylni oʻqiydi. Shunday qilib bitta xato ikki marta
takrorlanmaydi — jamoadoshingiz xatodan oʻrganadigan boʻladi.
