# prds/ — texnik tavsiflar (spec)

Har feature qurilishdan oldin shu yerda tavsiflanadi: `prds/<feature>.md`. Format:

```markdown
# <Feature nomi>
Nima uchun: <foydalanuvchiga nima beradi, bir-ikki jumla>
Nima qiladi: <aniq xatti-harakatlar roʻyxati>
Nima QILMAYDI: <chegara — bu ham muhim>
Qanday tekshiramiz: <tayyor boʻlganini qanday bilamiz — sanab oʻtiladigan mezonlar>
```

Mahsulot darajasidagi PRD ham shu papkada: `daftar-prd.md` — u butun mahsulotni tavsiflaydi,
`<feature>.md` fayllari esa har bir qismini.

Spec — saqlab boriladigan hujjat: kod oʻzgarsa, spec ham yangilanadi. Agentlar shu faylni
oʻqib quradi — spec qancha aniq boʻlsa, natija shuncha toʻgʻri.
