# platform/ — kod

Daftar ilovasining kodi shu yerda yashaydi. Kurs davomida bu papka agentlar jamoasi tomonidan
toʻldiriladi: dashboard, kirim-chiqim yozuvlari, qarz daftari, oylik hisobot.

Boshlangʻich holatda boʻsh — bu ataylab: birinchi kod ham kursda, kameraning oldida, spec
asosida yoziladi.
