# memory/ — sessiya eslatmalari

Har ish-sessiya yakunida bitta fayl: `memory/YYYY-MM-DD.md`. Format:

```markdown
# YYYY-MM-DD
Nima oʻzgardi: <qilingan ishlar, 2–4 qator>
Qayerda toʻxtadik: <keyingi sessiya nimadan boshlaydi>
Kutilmagan narsa: <boʻlsa — bir qator; boʻlmasa yozilmaydi>
```

Bu — 12 soatlik miya eslatmasi: bugun qilganingiz ertaga esdan chiqmasligi uchun. Yangi sessiya
avval eng yangi memory-faylni oʻqiydi va davom etadi — qayta tushuntirish yoʻq.
