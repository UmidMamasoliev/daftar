# discovery/ — ochiq savollar

Har hal boʻlmagan savol — bitta fayl: `discovery/<savol-qisqacha>.md`. Format:

```markdown
# Savol: <bir jumlada>
Nega muhim: <bir-ikki jumla>
Variantlar: <koʻrilayotgan yoʻllar, har biri bir qator>
Holat: <oxirgi oʻylangan narsa — keyingi sessiya shu yerdan davom etadi>
```

Savol hal boʻldi → bu fayl oʻchadi, qaror `decisions/` ga koʻchadi. Discovery — loyihaning
ishchi xotirasi: kontekst tozalansa ham, bu papka esida qoladi.
